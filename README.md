# Restaurant_Reviews_Project
Developed a sentiment analysis model to classify restaurant reviews as positive or negative using Natural Language
Processing (NLP) techniques.
Performed data cleaning, text preprocessing, tokenization, and sequence padding to prepare review data for model
training.
Implemented Deep Learning models using TensorFlow and Keras to analyze customer sentiments from textual reviews.
Evaluated model performance and optimized training workflows to improve sentiment prediction accuracy and
reliability.
Tech Stack: Python, NLP, TensorFlow, Keras, Pandas, NumPy, Deep Learning
